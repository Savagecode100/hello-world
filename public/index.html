Make beautiful maps of anywhere, with your data on top.

Atlas is an intuitive, open GIS platform. Search any geography in the world, switch basemap styles at any scale, layer your datasets with preloaded map types — clusters, heatmaps, bubbles, choropleths — then export PNGs with legends or share fully interactive maps anywhere via embeds and the SDK.

Start mapping — it's free Read the docs

Any geography on Earth

Built-in worldwide geocoding flies you to any country, city, address, or landmark. Seven basemap styles — streets, satellite, terrain, dark, and more — at every scale.

Your data, instantly mapped

Drop in a CSV or GeoJSON — like every one of your company's locations — and render it with preloaded map types: pins, clusters, heatmap, bubble, choropleth, route.

Legends & polished output

Every map type generates its legend automatically, with real values from your data. PNG exports always include the legend, your title, and attribution.

Share interactive maps

One dialog gives you a shareable link, an iframe snippet, and an SDK snippet that reproduce your exact map — live and interactive for anyone you send it to.

Open data by design

Published datasets are licensed (CC BY 4.0 by default), publicly cataloged, downloadable as raw GeoJSON, and every event is recorded in a public activity log.

Developer kit included

A REST API and a single-file JavaScript SDK ship out of the box. Sign in for an API key and put Atlas maps inside any outside application.

Maps in your app, four lines.

The Atlas SDK loads the rendering engine, fetches your published dataset, applies the map type, and draws the legend. Authentication is one header with your API key. Full documentation → 

<div id="map" style="height:400px"></div>
<script src="https://your-atlas-host/sdk/atlas-sdk.js"></script>
<script>
Atlas.createMap('#map', {
  style: 'dark',                  // 7 basemap presets
  mapType: 'bubble',              // 6 preloaded map types
  dataset: 'acme-locations',      // any published open dataset
  valueProperty: 'revenue_musd',  // drives size & legend
  title: 'Revenue by location'
});
</script>
