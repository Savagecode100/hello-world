Atlas SDK examples

Each map below is created with a few lines of JavaScript against the Atlas SDK — this is how you embed Atlas maps in any outside application. An iframe embed needs zero JavaScript: just point it at /embed?….

1. Cluster map of company locations

Atlas.createMap('#map-clusters', {
  style: 'light',
  mapType: 'clusters',
  dataset: 'acme-locations'
});

2. Bubble map sized by revenue

Atlas.createMap('#map-bubble', {
  style: 'dark',
  mapType: 'bubble',
  dataset: 'acme-locations',
  valueProperty: 'revenue_musd'
});

3. Heatmap of location density

Atlas.createMap('#map-heat', {
  style: 'dark',
  mapType: 'heatmap',
  dataset: 'acme-locations'
});

4. Inline GeoJSON, satellite basemap, geocoded fly-to

const m = await Atlas.createMap('#map-inline', { style: 'satellite' });
await m.flyToPlace('Grand Canyon');

5. Zero-JS iframe embed

<iframe src="https://your-atlas-host/embed?dataset=acme-locations
  &maptype=pins&style=streets&center=-96,38&zoom=3"></iframe>
